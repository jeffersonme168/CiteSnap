# Chrome Web Store 上架文案

## 简短描述（132字符以内）

从AI搜索引擎的回答中提取引用来源，支持导出为 CSV/JSON/Markdown，适用于GEO分析。

## 详细描述

CiteSnap 帮助 GEO（Generative Engine Optimization）从业者从 AI 搜索的回答中一键提取引用数据，无需逐个手动复制链接。

支持平台：DeepSeek、ChatGPT、豆包、Perplexity AI、通义千问、腾讯元宝、文心一言。

核心功能：

• 多轮对话提取 — 正确配对每轮提问与对应的引用来源
• 多格式导出 — 支持 CSV、JSON、Markdown 下载
• 实时检测 — 等待流式输出完成后自动提取
• SPA 感知 — 切换对话时自动更新内容
• 手动刷新 — 随时重新提取最新结果

使用方法：

1. 在支持的平台上进行一次联网搜索对话
2. 等待回答完毕
3. 点击浏览器工具栏中的 CiteSnap 图标
4. 查看提取结果
5. 选择格式导出数据

隐私说明：

• 所有处理均在本地浏览器完成，不上传任何数据到外部服务器
• 仅在用户主动点击时激活
• 不收集、不存储、不分享任何个人信息
• 最小权限：仅使用 activeTab 和 session storage
